# TUTORIAL - GEMINI CLI

### SYSTEM REQUIREMENTS
* Node.js version 20 or higher installed.
* Personal Google Account

## STEP 1
- Open Terminal and run code
```
npm install -g @google/gemini-cli
```

- Type the following code to launch Gemini CLI
```
gemini
```

- Type /quit to quit Gemini CLI
```
/quit
```
